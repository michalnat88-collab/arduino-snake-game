# קוד משחק סנייק על Arduino Uno

[פתיחת קוד המשחק המלא](snake_game/snake_game.ino)

הקוד מפעיל משחק סנייק על מטריצת לדים 8×8 באמצעות בקר MAX7219 וספריית `LedControl`. ארבעה לחצנים שולטים בכיוון התנועה. הנחש גדל כשאוכלים מזון, והסיבוב מסתיים בהתנגשות בקיר או בגוף.

## מהלך התוכנית

`setup()` מפעילה את התצוגה, מגדירה את הלחצנים כ־`INPUT_PULLUP` וזורעת את המחולל האקראי באמצעות קריאת A0. במסך הפתיחה מוצג משולש, והתוכנית ממתינה ללחיצה ולשחרור כדי לבחור כיוון התחלה.

`newGame()` יוצרת נחש באורך 2 במרכז הלוח, מאפסת את קצב המשחק ומגרילה מזון. מיקומי החוליות נשמרים בשני מערכים: `snakeX` ו־`snakeY`; אינדקס 0 מייצג את הראש.

בכל סבב של `loop()` נקראים הלחצנים, מתעדכן הבהוב המזון ונבדק אם הגיע הזמן להתקדם. התנועה וההבהוב מתוזמנים באמצעות `millis()`.

`moveSnake()` מחשבת את מיקום הראש הבא ובודקת פגיעה בקיר או בגוף. אם התנועה תקינה, הגוף מוזז מסוף המערך לכיוון הראש. כשהראש מגיע למזון, האורך גדל בפיקסל, מוגרל מזון חדש והמשחק מאיץ.

`drawGame()` מציירת את הנחש ואת המזון. בזמן הציור מופעל שיקוף של ציר X באמצעות `MIRROR_X`. בהתנגשות, `gameOverAnimation()` מציגה X למשך שנייה ומסך ריק לחצי שנייה, ולאחר מכן חוזר מסך הפתיחה.

## הפונקציות המרכזיות

| פונקציה | תפקיד |
| --- | --- |
| `showStart()` / `waitForStart()` | הצגת משולש והמתנה לתחילת סיבוב |
| `newGame()` | איפוס נתוני המשחק |
| `readButtons()` | קריאת הלחצנים ודחיית כיוון הפוך לתנועה הנוכחית |
| `createFood()` | הגרלת מזון במיקום שאינו בגוף הנחש |
| `hitsSnake()` | בדיקת חפיפה עם גוף הנחש |
| `moveSnake()` | תנועה, התנגשויות, גדילה והאצה |
| `drawPixel()` / `drawGame()` | ציור המשחק עם שיקוף ציר X |
| `gameOverAnimation()` | אפקט סיום הסיבוב |

## הגדרות הקוד

הלוח בגודל 8×8, ומערכי הנחש מכילים עד 64 מיקומים. מרווח התנועה מתחיל ב־700 מילישניות, מתקצר ב־30 בכל אכילה ואינו יורד מתחת ל־300. המזון משנה את נראותו כל 300 מילישניות, ובהירות המטריצה מוגדרת ל־5.

פיני התצוגה הם `DIN = D11`, `CLK = D13` ו־`CS = D10`. הלחצנים מחוברים לפינים D2–D5 ונקראים כ־`LOW` בזמן לחיצה.

| פין לחצן | כיוון לוגי שהקוד בוחר |
| --- | --- |
| D2 | `RIGHT` |
| D3 | `LEFT` |
| D4 | `UP` |
| D5 | `DOWN` |

המיפוי ושיקוף התצוגה נשמרו כפי שהם בקוד המקורי.
